BKR Robot app - install on Android (Galaxy A56)

1) Upload ALL the files in this folder (index.html, manifest.webmanifest, sw.js, icon-192.png, icon-512.png) to an HTTPS host (GitHub Pages recommended).
2) Open the link in Chrome on the phone.
3) Chrome menu (three dots) -> "Add to Home screen" -> Install.
4) BKR appears as an app icon and opens full screen.
